# CANVO E-commerce — Free Prototype

## Run
Open `index.html` in Chrome/Edge.

## Structure
- index.html — homepage
- css/style.css — design
- js/products.js — demo products
- js/app.js — cart/search/wishlist demo
- images/logo.png — CANVO logo

This is a frontend prototype. Checkout, real database, payment gateway, admin panel and real order processing are not connected yet.
